ZJ HUB v1.6.26
OOPZ 交流频道：881695

本版重点：删除液态玻璃主题，在保留现有视觉和功能的前提下减少界面阻塞，并新增大厅聊天指令。

大厅聊天指令
- /player：查看当前在线的 ZJ HUB 软件大厅玩家，数据来自大厅在线状态，不是 Minecraft 服务器全部玩家。
- /help：查看当前可用的指令及用法。
- 两条指令及结果仅在本机处理，不广播到公共聊天频道。

主题与交互
- 保留明亮、暗色、暖砂三套主题；暗色与暖砂不使用蓝紫主题色。
- 保留既有布局、图标、动画、顺滑滚动和背景视差，移除液态玻璃及其运行时图像处理依赖。
- 重复选择当前主题时维持选中状态，不再重复应用全局样式。

流畅度优化
- Qt 事件过滤提前跳过无关事件，减少绘制和布局过程中的额外工作。
- 聊天按完整消息内容复用气泡，保留文字选择、身份样式与滚动行为；任务栏结果不变时不重建表格。
- 设置仅刷新相关控件；音量实时生效，拖动时合并保存并在正常关闭时写入最终值。
- 回放扫描、ZIP 信息读取、目录查找和导入前的目录确认移至后台。
- 合并重复刷新，丢弃旧目录或旧选择的结果，避免覆盖手动输入；空闲时停止轮询。
- 输出路径编辑不逐字访问磁盘；关闭窗口不等待慢磁盘查询。

相对上一公开版 v1.6.3 的主要进展
- 完善 ZJ HUB 内置 Flashback 录制引擎，适配 Minecraft 1.21.10 / NeoForge 21.10.64，并保留原 1.20.1 录制路径。
- 更新大厅/子服切换时的连接配置采集与转换处理，增加录制质量诊断；不完整数据会明确提示或拒绝不安全的导出，并保留原始录制。
- 补充大厅 NPC 的玩家资料与皮肤采集；软件皮肤使用本次运行临时缓存，播放器副本保存在所选版本目录的 flashback/recorded_skins。
- 进程检测使用进程内 WMI 与 Windows 模块快照，不再周期启动 PowerShell；移除开发机固定目录，后台发现并验证 x64 JDK。
- 新增对局数据与 Flashback 的可保存设置，统一数值控件、滚动条和文字层级；Flashback 页面先显示引擎日志，再显示最近回放与回放信息。
- 主界面更新为 OOPZ 交流频道 881695 标识，调整主题和滚动交互。

验证范围
- UI 回归及最终 EXE 的本机新配置、中文只读安装目录、高 DPI 隔离启动检查，具体结果见 performance-notes 附件。
- 核对成品模块、内置录制引擎及源码包内容，并提供 SHA256 校验值。
- 本机指定聊天操作的主线程处理耗时中位数约 67.55 ms → 1.35 ms；完整测量方法及其他结果见 performance-notes 附件。这不是整机帧率承诺。
- 本版未改动录制协议或转换算法；上述检查不替代全新 Windows 虚拟机、长时间真实录制、多次转服及完整回放验收。

运行与使用
- Windows 10 / 11 x64。关闭旧版后运行 ZJ-HUB-v1.6.26.exe；无需另装 Python 或 .NET。
- 录制另需含 jdk.attach 的 x64 Java 17+ JDK，现代游戏组件需要目标游戏运行于 Java 21+。
- 配套播放器：Minecraft 1.21.11 / Flashback 0.39.10。
- 回放皮肤请通过 ZJ HUB 的安装已有回放或自动导入流程安装；已有手工皮肤设置会保留。
- 如录制或导出异常，请保留 .flashback-runtime 原始数据、引擎日志与质量报告。旧录制缺少的真实皮肤无法凭空恢复。
