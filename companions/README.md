# ZJ HUB 配套整合包

`ZJ-HUB-modpack.zip` 是用户提供的 `ZJ HUB.zip` 原始文件，内容未改动。

- Minecraft：1.21.11
- Fabric Loader：0.19.3
- 格式：Modrinth 整合包清单及配置（`modrinth.index.json` 和 `overrides`）
- SHA256：`b2b5054e6656da423abd8a67ef66875f821e4534d66c48239d84764f8a12dd25`

ZJ HUB 的 **Flashback → 录制控制 → 点我下载配套整合包** 可将内置包离线保存为 `ZJ HUB.zip`。
Release 页面也提供 `ZJ-HUB-modpack.zip` 单独下载。
这是启动器导入包，首次导入时由支持 Modrinth 整合包的启动器下载清单中的模组。
