# 逐渐优化器 · DEV King

面向起床战争的工具中心，包含电脑清理、快捷工具、战局数据、排行榜和大厅聊天预留分区。

## 下载

前往 [GitHub Releases](https://github.com/zhujianmengbi-droid/-/releases) 下载 Windows EXE 和源码包。

## 自动更新

程序启动后会在后台查询本仓库的最新 Release。发现更高版本时，窗口顶部会出现“可更新”提示；点击后打开 GitHub 发布页。

## 当前版本

v2026.09.29.1

## 快捷工具

TaskbarSwitcher 窗口切换功能已整合到“快捷工具”。默认全局快捷键为 Alt+1 至 Alt+0，可在“设置 → 快捷工具插件”中换绑。

## API 与主题

- 内置默认 API Token，设置中可以替换；高峰期可在游戏内输入 `/openapi` 获取自己的 Token。
- 支持明亮、玻璃、暗色和深海蓝主题。
- 需要 Windows 10 或 Windows 11。
