本版本更新与修复汇总
- 打包配置：保留 OpenSSL 3 (libcrypto-3-x64.dll / libssl-3-x64.dll)，由 Windows 提供系统 ICU；隔离打包环境中的外来同名 ICU，避免 QtCore 缺失入口点而无法启动。构建脚本检查 CaptureQuality.cs 完整性。
- 首次启动登录：新增“配置 Token”折叠输入与“稍后登录”免登录入口，避免默认 Token 触发限流（HTTP 429）时阻断工具箱打开。
- 权限提升与进程退出：修复 UAC 提权重启时打包版参数重复问题，并在提权成功后自动释放热键、关闭录制引擎并退出旧普通进程，避免热键与引擎互斥锁冲突。
- 垃圾清理与安全过滤：缩略图缓存清理仅匹配 thumbcache_*.db（保留 iconcache_*.db 避免桌面图标闪烁重建）；修复重复清理累加计数与 DNS 刷新 1B 虚增统计。
- 对局历史与今日汇总：修复第 2 页及后续分页在今日扫描已拉取时无法渲染上屏的问题；为非严格有序对局页增加跨日与页数上限保护，防止无限翻页请求。
- 任务栏窗口切换：等待全部修饰键（含 Shift/Win）释放后再点击任务栏，避免触发 Shift+Click 新开应用实例；放宽窗口标题后缀/子串匹配，消除切换成功后的误报异常。
- 大厅聊天与设置同步：为 Supabase Realtime 频道加入握手增加 10 秒超时重连保护；同步“常规设置”与“大厅身份”两处的提示音开关和音量滑块；为 lobby_server.py 限流窗口增加过期清理防内存泄漏。
- Flashback 录制引擎与整合包：支持自动探测注册表、常见目录、启动器目录与运行中 Minecraft 进程的带 jdk.attach Java 运行时；清理锁文件回退产生的历史临时 JAR；修复自定义输出目录时向上两级递归全盘扫描的卡死隐患；修复导出文件占用回退时丢失 .flashback.zip 双后缀的问题；对时间线标记做转义与同 tick 去重；清理配套整合包中的个人路径与窗口坐标残留。
- 动画与生命周期保护：修复动画速度设为“关闭”时详情面板透明不可见的问题；使用单次信号连接保护关闭窗口时的后台线程等待回调。

构建
1. 在 Windows 上安装 Python 与 .NET 8 SDK，并运行：python -m pip install -r requirements.txt
2. 在此目录运行：python build_large.py
3. 可执行文件位于 dist\ZJ HUB.exe。

快捷工具
- 将 TaskbarSwitcher 的任务栏窗口切换功能集成到“快捷工具”。
- 列表按主任务栏从右往左排列，支持筛选、双击和按钮切换；窗口列表在后台读取，界面不等待 UI Automation。
- 全局热键默认是 Alt+1 到 Alt+0，可在“设置 → 快捷工具插件”逐个换绑；支持 Ctrl、Alt 或 Win 加字母、数字或 F1–F12。
- 重复或被系统占用的按键会显示未注册状态，可在设置里换用其他组合键；提供恢复默认按键操作。
- 热键对应当前主任务栏顺序，应用会在“快捷工具”页面打开时每 5 秒刷新一次，并可手动刷新。

大厅聊天
- 首次启动可验证布吉岛游戏 ID（或稍后在“设置 → 大厅身份”验证），验证成功后保存到当前 Windows 账户，并同步到战局查询、最近查询和大厅聊天身份。
- 大厅聊天页提供公共频道、实时在线人数、主题化消息气泡、表情面板和发送框，不提供私聊。发送等待服务端确认，失败会恢复文本，重复消息使用唯一 ID 去重。
- 大厅聊天消息会在本机保存最多 80 条当前运行缓存，页面切换或重绘时可恢复；正常关闭软件前主动清除，不会作为历史记录长期保留。
- 大厅收到新消息时播放可关闭的提示音；“设置 → 常规设置”或“设置 → 大厅身份”均可开启或关闭，并用音量滑块调整 0–100% 音量。

对局数据与排行榜
- 应用内置了默认 API Token，首次运行会尝试用 Windows DPAPI 加密保存在当前账户；如遇高峰期限流，可在登录界面或“设置 → API 连接”替换个人 Token（游戏内输入 /openapi 获取）。
- 双击对局会在当前 GUI 内切换到绑定的详情面板；列表支持向下滚动连续加载后续分页，今日汇总按中国时区自动跨页统计。
- 工具箱提供“排行榜”分区，可按玩法、指标、端游/手游切换日榜、周榜、年榜和总榜。
