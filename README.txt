ZJ HUB 源码包 v1.3

本版本更新
- 未打开大厅聊天时收到其他玩家消息，侧栏聊天入口显示未读红点；进入聊天页后清除。
- 消息列表在滚动范围更新后平滑跟随至最新消息。

构建
1. 在 Windows 上安装 Python，并运行：python -m pip install -r requirements.txt
2. 在此目录运行：python -m PyInstaller --noconfirm 电脑优化中心.spec
3. 可执行文件位于 dist\ZJ HUB.exe。

快捷工具
- 删除原“网络工具”入口，将 TaskbarSwitcher 的任务栏窗口切换功能集成到“快捷工具”。
- 列表按主任务栏从右往左排列，支持筛选、双击和按钮切换；窗口列表在后台读取，界面不等待 UI Automation。
- 全局热键默认是 Alt+1 到 Alt+0，可在“设置 → 快捷工具插件”逐个换绑；支持 Ctrl、Alt 或 Win 加字母、数字或 F1–F12。
- 重复或被系统占用的按键会显示未注册状态，可在设置里换用其他组合键；提供恢复默认按键操作。
- 热键对应当前主任务栏顺序，应用会在“快捷工具”页面打开时每 5 秒刷新一次，并可手动刷新。
- 切换到深色、明亮、玻璃或深海蓝主题时，窗口列表、状态、筛选框和操作按钮同步换色。
- 大厅聊天入口已连接公共聊天客户端；服务端部署配置见 `lobby_server.py`、`requirements-chat.txt` 和 `render.yaml`。
- 首次启动会先验证布吉岛游戏 ID，验证成功后保存到当前 Windows 账户，并同步到战局查询、最近查询和大厅聊天身份；设置 → 大厅身份可重新验证并换绑。
- 大厅聊天页提供公共频道、实时在线人数、主题化消息气泡、表情面板和发送框，不提供私聊。发送等待服务端确认，失败会恢复文本，重复消息使用唯一 ID 去重；发言身份始终跟随已验证的登录游戏 ID，换绑时会关闭旧聊天连接。设置 → 大厅身份可保存公共服务器或自托管地址并立即连接。服务端部署配置在 `lobby_server.py` 与 `render.yaml`，默认目标为 Render 新加坡节点（距离中国大陆较近，但免费 Render 节点不保证中国大陆网络稳定）。
- 大厅聊天消息会在本机保存最多 80 条当前运行缓存，页面切换或重绘时可恢复；正常关闭软件前主动清除，不会作为历史记录长期保留。
- 大厅收到新消息时播放可关闭的提示音；设置 → 大厅身份可开启或关闭，并用音量滑块调整 0–100% 音量。自己的发送回显不会重复提示。

对局数据
- 应用内置了默认 API Token，首次运行会尝试用 Windows DPAPI 加密保存在当前账户。
- 在“设置 → API 连接”可替换并加密保存令牌；输入框默认隐藏令牌内容。
- 如果遇到高峰期，可以在游戏内输入 /openapi 自行获取 API Token。
- 最近查询在本机保留 5 个昵称，点击即可重新查询。
- 双击对局会在当前 GUI 内切换到绑定的详情面板；不再弹出独立窗口。
- 详情用绿色/红色结果胶囊区分正负表现，并高亮查询的人、MVP 和关键数据；玩家卡片使用所属队伍的红/蓝/黄/绿背景，另以绿色“未淘汰”和红色“已淘汰”标记状态。
- 对局胜负以整条绿/红胶囊展示。列表先加载，地图、时长和个人统计随后自动补齐。
- 今日汇总使用服务器中国时区，按最近对局顺序继续翻页至跨日或空页；去重后汇总。
- 汇总同步期间会显示进度；尚未返回的个人数据显示“—”，部分合计使用“+”提示。
- API 请求串行执行，间隔至少 2.2 秒，并保留 28 次/分钟保护。详情、翻页和排行榜查询优先。

排行榜
- 工具箱新增“排行榜”分区，可按玩法、指标、端游/手游切换日榜、周榜、年榜和总榜。
- 榜单结果按条件缓存，支持官方返回的常见列表结构；高峰期可在游戏内 /openapi 更换 Token。

界面输入框
- 搜索框与 API 令牌框在五种主题下都使用不透明背景，并统一处理悬停与聚焦状态。
- 拖动期间保持窗口绘制和 DWM 模糊；输入框、滚动区、按钮和详情面板不会触发主窗拖动。
- 清理/对局/详情滚动容器的透明样式仅作用于容器本身，不再覆盖内部卡片。
- 程序关闭时会等待正在进行的网络线程安全结束，避免销毁仍在运行的线程。
- 启动时不再显示独立出场动画，主窗口自身约 0.5 秒平滑展开并淡入；按钮、页面切换和详情卡片使用淡入/按压过渡。
- 设置 → 性能 → 动画与反馈可选择关闭、快速、标准或慢速，选择会保存在本机。
- 所有下拉框使用统一的主题化无黑边弹出层，选项固定从控件下方展开；弹层背景、文字、边框和悬停态跟随五套主题。
- 快捷工具插件页面不再对含原生任务栏表格的整页施加透明淡入，避免 Windows 合成器首帧产生黑色镂空条；插件控件继续保留主题和交互动画。
- 排行榜的模式、指标、周期和平台选项一次完整展开，隐藏滚动条，不需要滚轮逐项寻找。
- 对局详情中最终击杀超过 8、击杀超过 15、伤害超过 400、绿宝石超过 100、钻石超过 80 的指标会显示主题适配的金色高光；详情顶部两块概览区域使用中性主题表面，避免失败状态整块变红。
- 详情中的击杀、死亡、拆床、伤害、绿宝石、钻石、放置、破坏和承伤等数据前均有统一线性 SVG 图标，并随主题和高光状态换色。
- 详情中的 11 项固定指标始终完整显示；API 缺少字段、返回空值或非法值时显示为 0，不再省略数据卡。
- v1.2 删除液态玻璃主题及其动态背景层，保留四套稳定主题；清理重复按钮事件动画和无效重绘路径，保持现有视觉并提升流畅度。
- 流畅度优化：详情/列表重建采用批量绘制，重复的主题样式和 SVG 图标会复用缓存，状态文本不变时不会重复触发重排与重绘；视觉样式和交互时序保持不变。
- 圆角统一：导航、设置按钮、下拉框、提示框、复选框和滚动条手柄补齐主题圆角，并按控件大小使用 4/8px 等小半径；全屏设置覆盖层继续保持完整覆盖。
- 更新检查：启动约 1.8 秒后在后台检查 GitHub 最新 Release；发现新版本时在窗口顶部显示“可更新”，点击“打开 GitHub”跳转发布页。当前为手动前往 GitHub 获取更新，不会自动下载或安装。当前发布仓库为 https://github.com/zhujianmengbi-droid/-。
